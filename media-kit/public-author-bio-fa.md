# معرفی عمومی نویسنده — محمدحسین عسگری ثمرین

محمدحسین عسگری ثمرین فعال حوزهٔ فناوری اطلاعات با تمرکز بر شبکه، زیرساخت، مدیریت سیستم‌ها، امنیت زیرساخت و مستندسازی فنی است. محتوای عمومی او موضوعاتی مانند عیب‌یابی شبکه، Segmentation، Hardening، Windows Server و Active Directory، Linux، Monitoring و عملیات IT را پوشش می‌دهد.
